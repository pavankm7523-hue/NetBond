# NetBond v0.1.3

This release cleans up the Network dashboard so it shows usable, user-facing Internet adapters instead of Windows networking internals.

## Fixed

- Show physical Wi-Fi and Ethernet adapters.
- Keep explicit USB/RNDIS tethering and cellular/WWAN adapters eligible.
- Hide WAN miniports, Teredo, 6to4, IP-HTTPS, hotspot internals, kernel-debug devices, and other ghost interfaces.
- Exclude devices that Windows reports as not present.

It includes the BitTorrent metadata and stale-interface fixes from v0.1.1 and v0.1.2.
