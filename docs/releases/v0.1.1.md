# NetBond v0.1.1

This maintenance release fixes BitTorrent metadata review for both `.torrent` files and magnet URIs.

## Fixed

- Metadata review no longer requires a network adapter to be selected first.
- Reviewing metadata no longer creates or locks the source-bound download session.
- The current adapter selection is refreshed and validated when **Download selected files** is clicked.
- The interface now explains whether metadata used a selected adapter or the normal Windows route.

The download itself still requires at least one connected adapter to be selected on the **Network** page.
