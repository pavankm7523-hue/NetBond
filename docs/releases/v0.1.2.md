# NetBond v0.1.2

This release fixes Windows network discovery on systems containing stale or removed virtual, hotspot, VPN, or USB-tether adapter records.

## Fixed

- A missing `MSFT_NetIPInterface` record no longer aborts the entire adapter scan.
- IP configuration is queried once and safely matched to existing adapters.
- Missing IPv4, IPv6, and gateway entries are returned as empty lists instead of invalid `null` values.
- Connected adapters such as Wi-Fi remain available even when Windows retains broken hidden adapters.

It also includes the v0.1.1 BitTorrent metadata-review fix.
