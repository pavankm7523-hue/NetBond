# NetBond v0.1.4

This release fixes BitTorrent UDP tracker initialization with source-bound, IPv4-only Windows adapters.

## Fixed

- rqbit's dual-stack UDP tracker socket now falls back to a source-bound IPv4 socket when selected adapters have IPv4 addresses only.
- Torrent metadata review no longer fails with `invalid bind device` at `[::]:0`.
- The same fix covers the source-bound torrent download session.
- Added a Windows regression test that initializes tracker and DHT clients using active selected adapter addresses.
