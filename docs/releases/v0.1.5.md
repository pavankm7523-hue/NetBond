# NetBond v0.1.5

This release makes torrent progress and each selected network's real contribution much easier to see.

## Improved

- Added a prominent overall percentage, progress bar, downloaded size, total size, speeds, peers, seeds, and ETA.
- Added an expandable file list with the actual downloaded bytes and progress of every selected torrent file.
- Each network now shows its actual torrent download speed, downloaded bytes, and percentage contribution.
- USB NCM tethering adapters are identified as USB tether connections.
- Changing selected adapters while a torrent is active updates the source pool used for new peer connections.

Existing peer sockets remain on their original interface until they reconnect. NetBond reports actual peer traffic and does not claim unused interfaces are contributing.
