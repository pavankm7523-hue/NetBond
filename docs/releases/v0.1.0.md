# NetBond v0.1.0

The first public 64-bit Windows release includes HTTP(S) multi-interface range downloading, BitTorrent support, and real per-interface bandwidth monitoring.

## Downloads

- **Setup EXE:** recommended
- **MSI:** Windows Installer package
- **Portable EXE:** run without installation
- **SHA256SUMS.txt:** integrity checksums

The binaries are not code-signed, so Windows SmartScreen may warn on first launch.
