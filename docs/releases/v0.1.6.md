# NetBond v0.1.6

This release adds destination selection to BitTorrent downloads.

## Improved

- Added a native **Choose folder** button on the BitTorrent page.
- The destination can be selected before reviewing metadata or starting a download.
- The chosen path is clearly confirmed below the torrent file list.
- The default location still follows the folder configured in Settings.
