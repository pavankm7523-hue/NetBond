# Security policy

The latest published NetBond release receives security fixes.

Report vulnerabilities through GitHub's private vulnerability reporting for this repository. Do not open a public issue for a weakness that could expose users, files, or traffic.

Include the affected version, Windows version, reproduction steps, impact, and mitigation. Never include credentials, private torrent identifiers, or sensitive URLs.

Release binaries are currently unsigned. Download only from this repository's Releases page and verify the published SHA-256 checksum.
